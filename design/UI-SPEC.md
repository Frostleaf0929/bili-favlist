> 目标：把现有 8 个朴素标签页重构为一套有统一设计语言的本地工作台。

### 从 TallyMoment 26 轮迭代里提炼的"家规"（踩坑换来的，必须遵守）

1. **毛玻璃要可见，底必须透**：玻璃面 = 半透明表面 + `backdrop-filter`，且要有一层带强调色柔光的背景层托底；"关闭"档必须回到实底（防黑底/闪烁）。
2. **一个旋钮喂所有玻璃面**：玻璃模糊、底色不透明度是全局 token，不逐卡片设。
3. **`backdrop-filter` 会创建包含块**：会把 `position:fixed` 的弹层困住 → 弹层一律用原生 `<dialog>`（顶层渲染，天然躲开此坑）。
4. **整体一块**：侧栏/内容/卡片共用同一套材质，之间只留一条淡分隔线；不要做出"独立配色的标题栏/面板"这类割裂面（拾刻曾因此被连驳三轮）。
5. **图表降噪**：弃彩虹色，用**单色系透明度阶梯**；图例自绘放图上方；柱宽设上限；主题切换时关闭重绘动画。
6. **侧栏**：品牌放侧栏顶部（兼收展开关）；激活项左侧 3px 强调色竖条；折叠 = 图标条。
7. **危险操作**：删除/执行类按钮做"胶囊展开"（圆形图标 → 悬停浮出文字）；确认走输入确认串。
8. **滑杆即时反馈**：本地值即时生效 + 松手提交。
9. **不要自作主张加装饰**（拾刻第五轮"我没有让你动的你不要动"）：颜色与风格改动必须先问。

## 2. 设计原则

1. **token 单一真源**：全部颜色/间距/圆角/字号/动效 = CSS 变量，深浅主题 + 强调色 + 玻璃参数都由 `data-*` 属性切换，JS 只改属性不改样式。
2. **数据优先**：数字一律 `tabular-nums`；表格是主角，chrome（边框/底色）保持安静。
3. **安全可见**：三层保护、限额、APPLY 双确认在界面上"看得见"——锁定=🛡、软保护=⚠、自由=○，危险区独立描边卡。
4. **留白与密度可调**：默认舒适，表格密度一键切紧凑。
5. **全中文**，无中英混杂按钮；空态给原因不给白板。

## 3. 新信息架构（IA）

旧 8 个平铺标签页 → 新 **6 项主导航 + 设置**，侧栏分组：

```
总览            （原"流水线"+"趣味数据"精华合并：状态、额度、重合率、分布）
整理
  ├ 条目库      （原"全部条目"）
  ├ 复核队列    （原"待审复核"，带角标数）
  └ 分类与规则  （原"分类体系"+"规则"合并，页内分段切换）
智能
  └ 学习与评估  （原"手动分类对比"，页内分段：盲测报告 | 语料与学习）
执行
  └ 写回        （保护/范围/限额 + 计划 + APPLY）
底部
  └ 设置与个性化（阈值、AI 接口、主题/强调色/材质/密度）
```

- 依据：拾刻第十一轮把低频"数据"并入"设置"获用户认可——同理，"趣味数据"降为总览的一张卡。
- 页内分段切换（分类·规则 / 报告·语料）沿用拾刻"详细·应用/事项"模式，减少侧栏噪音。

/* 深色主题（默认；bg 用 elevated 灰阶非纯黑，学 HIG/拾刻 #0f1116） */

/* 浅色主题（[data-theme=light]） */

/* 语义色（warn 沿用拾刻米黄，是既有审美决定） */
--ok:#34c77b(浅#1f9d64); --warn:#d3a95e(浅#b8893c); --danger:#ef5b6e(浅#d94a5c);

bili #23ade5(浅#00a1d6) · indigo #7b7ff2(浅#5856d6)〔默认〕 · mint #3ecfa5 · wisteria #b18cf0 · amber #e8a53e · rose #ef7ba0

/* 状态色（分类结果徽章，8 态；浅色主题用加深变体保证对比） */
auto #34c77b · hot #4f8cff · hot2 #b18cf0 · ai #3fc1c9 · human #2fb8a6 · review #d3a95e · low #8a93a6 · none #ef5b6e

## 5. 组件规范

| 组件 | 规则 |
|---|---|
| 卡片 `.card` | 半透明表面+1px 淡边+大圆角+柔和投影；hover 上浮 2px + 描边微染强调色；**不嵌套卡片** |
| 徽章 `.badge` | 状态色 15% 底 + 同色文字 + 6px 圆点；一行内不超过 2 枚 |
| 按钮 | primary=强调色实底；ghost=描边；danger=红实底；危险动作悬停胶囊展开（后续轮） |
| 表格 | 无竖线、细分隔线、表头小字灰、行 hover、数字 `tabular-nums`、标题列省略号+悬停完整 |
| 分段 `.seg` | 页内二级切换；激活片=实底片+投影 |
| 筛选 chip | 单选排他；激活=状态色 16% 底 |
| 额度条 `.meter` | 8px 圆角轨道，用量 >80% 转 warn 色 |
| 分布条 | 单色系透明度阶梯（0.85→0.17），禁彩虹 |
| 弹窗 | 原生 `<dialog>` + 磨砂 `::backdrop`（blur 14px），确认串输入后才可执行 |
| 空态 | 一句原因 + 一个动作按钮，不放插画 |
| toast | 底部居中浮出，2.6s 自散 |

## 7. 安全 UX 专项（写回页）

1. 顶部常驻三闸门徽章：`🛡 锁定 n` `⚠ 软保护 n` `○ 自由 n`。
2. 额度条在**顶栏与写回页双处**显示，>80% 变 warn 色。
3. 执行移动：危险区红描边卡 → 弹 `<dialog>`（磨砂遮罩、列出每一组 源→目标 与条数）→ 输入 `APPLY` 才解锁按钮；涉及软保护再要求 `CONFIRM-SOFT`。
4. 计划过期的竞态拒绝、限额不足，都在弹窗内给中文原因与出路。

## 8. 原型说明

- 内联预览：本会话对话内直接渲染（fragment）；定稿后复制为 `design/prototype.html`。
- **原型里真实可玩**：页面切换、分段切换、深浅主题、六强调色、毛玻璃开关、表格密度、侧栏收展、条目筛选、批量栏、APPLY 确认弹窗（含输入校验）。
- 数据全部为**虚构演示数据**（规则 7）；聚合数字（64%/79% 等）取自已公开的 README。
- 已知简化：图标用 Lucide（落实阶段换本地 SVG）；单文件无路由；表格 10 行示意。
